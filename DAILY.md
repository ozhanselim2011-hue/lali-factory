# Ежедневный запуск фабрики

Два вида запусков (МСК):
- **Основной** — 00:00, 06:00, 12:00, 18:00: всё ниже (выбор звуков + 2 готовых видео).
- **watch** — каждый час в остальные часы: только быстрые видео из НОВЫХ присланных звуков (см. в конце).
Всё общение с владельцем — через бота (`factory/tg.py`), по-русски, коротко.
**Идеи владельцу НЕ отправлять** — он хочет только готовые видео. Идеи сразу превращай в видео.
Запуски приходят в одну постоянную рабочую сессию: в начале каждого запуска `git pull` (папка могла пересоздаться),
в конце — обязательно `git push`.

## 0. Подготовка

```bash
cd lali-factory && git pull
python3 -c "import faster_whisper, shazamio" 2>/dev/null || pip install --only-binary=:all: faster-whisper shazamio
```

## 1. Забрать сообщения

```bash
python3 factory/tg.py pull && python3 factory/tg.py fetch && python3 factory/tg.py jobs
```

`pull` нужно сделать в каждом запуске: Telegram хранит непрочитанное только 24 часа.

## 2. Выбор звуков (каждый основной запуск)

1. Прочитай `notes` (идеи владельца) из `python3 factory/tg.py jobs` — они в приоритете.
2. Главное правило выбора: **самые новые и самые известные** звуки.
   - Самые известные: `python3 factory/tiktok.py chart RU 15` — чарт Shazam России прямо сейчас + официальный звук трека
     в TikTok, суммарные просмотры и хештеги. Это основной источник.
   - Самые новые: `python3 factory/tiktok.py trends BY 4` — звуки, которые за последние 1–3 дня быстрее всего набирают
     просмотры (BY — свежий русскоязычный фид; RU заморожен с 2022). Используй, если в чарте нет подходящего.
   - Дополни веб-поиском по русскому TikTok/Reels за последние 7 дней.
   Приоритет: трек есть в чарте Shazam И активно набирает в TikTok > просто высоко в чарте > просто быстрый рост в фиде.
3. Придумай сценарий под выбранный звук сам (карточки, что делает Лали) и сразу делай видео (шаг 3).
   Сверься с `state/ideas.md`, чтобы не повторять звуки и сюжеты; после отправки допиши туда звук + сюжет одной строкой.
4. `python3 factory/tg.py clear-notes` после того, как учёл заметки владельца.

## Выбор треков — пожелание владельца (ВАЖНО)

Брать только НОВЫЕ треки 2024–2026 годов, жанры — русский рэп и поп (хип-хоп, поп-рэп, вирусные TikTok-хиты).
НЕ брать: старые песни и ремейки (Буланова, «Ледяное сердце», «Чёрная смородина», Фабрика звёзд, 80-е/90-е/2000-е),
шансон, эстраду, романсы, саундтреки к сериалам, медляки «для души», иностранные треки.
Если год выхода неясен — проверь веб-поиском; сомневаешься — бери другой трек.

## 3. Два готовых видео (каждый запуск)

Сделай и отправь РОВНО 2 видео.
Порядок: сначала `fix` (с учётом `feedback`), потом `new` владельца, потом `new` гостей (поле `by`) — самые старые первыми. Остальные ждут следующего запуска.
Если в очереди меньше двух — добери сам по правилу «самые новые и самые известные» (шаг 2): сначала трек из
`tiktok.py chart RU` (с наибольшими просмотрами в TikTok), иначе самый быстрорастущий из `tiktok.py trends BY`.
Звук должен подходить формату (русская речь/текст с панчлайном, не детский контент, не реклама) и ещё не использоваться
(сверься с `state/tg.json` jobs и `state/ideas.md`). Скачай: `python3 factory/tiktok.py get <ссылка> "TikTok-тренд"`.
Если скачать не вышло (сервер TikTok не разрешён в сети среды) — возьми следующий; в крайнем случае сделай второй
вариант уже присланного звука (другой кусок/сценарий) и напиши владельцу, какой хост был недоступен.

Для каждого выбранного задания:

1. `python3 factory/shazam.py jobs/<id>/in.mp4` → SONG.
2. `python3 factory/transcribe.py jobs/<id>/in.mp4 large-v3 "<артист, трек, ключевые слова>" > jobs/<id>/transcript.txt`
   Если Whisper ошибся, а текст известен, — поправь слова вручную, таймкоды бери от Whisper.
3. Напиши `jobs/<id>/spec.py` (формат — в CLAUDE.md, образцы — `examples/v21…v30`).
4. Превью: `mkdir -p jobs/<id>/pv && python3 factory/build.py jobs/<id> && node factory/render.js jobs/<id>/scene_final.html jobs/<id>/pv 0 <START> <t1>,<t2>,<t3>` — посмотри кадры, поправь.
5. `./factory/make.sh jobs/<id>` → `jobs/<id>/out.mp4`.
6. Хештеги → `jobs/<id>/hashtags.txt` (одной строкой, 8–12 штук, все с `#`, без повторов):
   - 3–4 по треку: артист, название, их слитные варианты (`#земляк #koss #плутто`) — бери из тегов `tiktok.py chart`;
   - 2–3 по сюжету ролика (что происходит в сценах: `#пчёлы #мёд #отношения`);
   - 2–3 самых частых из свежего фида/чарта (`tiktok.py trends BY` → «Горячие хештеги»), только по-русски/нейтральные;
   - всегда: `#рекомендации #врек #fyp`.
   Не ставь чужие ники, политику, рекламу других брендов и теги, не связанные с роликом.
7. `python3 factory/tg.py video jobs/<id>/out.mp4 "🎬 <SONG>\n🔥 <откуда звук: чарт Shazam №N / тренд TikTok, просмотры>\n✅ готово к публикации. Если нужно поправить — ответь на видео текстом." <id>`
   — следом бот сам пришлёт исходный звук и хештеги (кнопкой «скопировать»).
   Владелец сам решает, что выкладывать. Ответ ✅/❌ — необязательный.

Если что-то сломалось — коротко напиши владельцу, что именно, не молчи.

## Ответы владельца под видео (ВАЖНО)

Владелец отвечает на присланное видео текстом (reply) — это правка: `tg.py pull` ставит заданию статус `fix`
и кладёт текст в `feedback` (видно в `tg.py jobs` и в `reviews=[…]` у `pull`).
- В КАЖДОМ запуске (и основном, и watch) после `pull` проверь `reviews` и все задания `fix` и сделай их первыми,
  строго по `feedback`. Если в `feedback` текст песни — субтитры только по нему (таймкоды подгони Whisper'ом,
  передав этот текст в prompt `transcribe.py`).
- Владелец может прислать текст песни сразу следом за звуком (ответом или отдельным сообщением в `notes`).
  Поэтому перед рендером звука владельца без распознанного текста сделай ещё раз `tg.py pull` и проверь
  `notes`/`feedback`; текст, пришедший вслед за звуком, относится к нему.

## 4. Сохранить состояние

```bash
git add -A && git commit -m "Run $(date +%F-%H) <mode>" && git pull --rebase origin main && git push origin main
```

Обязательно, иначе следующий запуск потеряет очередь и статусы.

## Режим watch (ежечасная проверка)

Цель — видео из присланного звука как можно быстрее.

1. `git pull`, затем `python3 factory/tg.py pull && python3 factory/tg.py fetch && python3 factory/tg.py jobs`.
2. Если нет заданий `new` и `fix` — закоммить `state/` (если изменился) и закончи. Владельцу ничего не пиши,
   пакеты и модель не ставь.
3. Иначе — подготовка (шаг 0) и шаг 3 для ВСЕХ `new`/`fix` (без лимита в 2), идеи не ищи.
4. Шаг 4. Перед пушем `git pull --rebase origin main` (мог параллельно идти другой запуск).
