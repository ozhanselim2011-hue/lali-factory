# Фабрика Лали

Делает короткие квадратные (1080×1080) ролики под трендовые звуки: по строчкам текста песни
идут анимированные «карточки»-сцены с персонажем Лали (человечек в кепке и очках), сверху
плашка с названием трека, снизу рекламная плашка `VPN в тг: @PluggerVpnBot`.

Владелец — Telegram @selyamchik (chat id в `factory/config.json`). Общение с владельцем — на русском.
Гости (любой другой в личке бота) могут присылать ТОЛЬКО звуки (не больше `guest_daily_limit` в сутки),
в ответ получают лишь «Звук принят». Их тексты, команды и отзывы игнорируются.
Готовые видео, идеи и всё остальное отправляются ТОЛЬКО владельцу — к видео автоматически
добавляется подпись «Звук от @username» и следом исходный звук (`tg.py video … <job_id>`).
Никогда не отправляй видео гостям и не ослабляй эти проверки в `factory/tg.py`.

## Структура

- `factory/tg.py` — бот: `pull` (новые звуки/идеи/отзывы), `fetch` (скачать звуки в `jobs/<id>/in.mp4`),
  `jobs`, `text`, `video`, `status`, `clear-notes`.
- `factory/tiktok.py` — TikTok через tikwm.com: `chart RU` (самые известные: чарт Shazam → звук в TikTok + хештеги),
  `trends BY` (самые новые: быстрее всего растущие за 1–3 дня), `get <ссылка>` (звук → задание).
- `jobs/<id>/hashtags.txt` — хештеги под видео; `tg.py video … <id>` присылает их владельцу отдельным сообщением.
  Ссылки на TikTok, присланные боту (владельцем или гостем), скачиваются автоматически в `tg.py fetch`.
- `factory/shazam.py` — название трека. `factory/transcribe.py` — текст с таймкодами слов (Whisper large-v3).
- `factory/gen.py` — шаблон сцены (spec.py → scene.html). `factory/build.py` — + Лали, плашка трека, VPN.
- `factory/make.sh jobs/<id>` — рендер в `jobs/<id>/out.mp4` (Playwright-кадры 30fps + ffmpeg + исходный звук).
- `factory/render.js scene_final.html <dir> 0 <START> 1.5,4,8` — PNG-превью для проверки кадров.
- `examples/v2…v30/spec.py` — 29 готовых роликов, образцы стиля. `examples/songs.txt` — какие треки были.
  v21–v30 — новый стиль (Лали внутри карточек через `HELPERS`: `place()`/`pose()`), ориентируйся на него.
  v2–v20 + `examples/lali_keyframes.py` — старый стиль (Лали поверх сцены через ключи `LK`).
- `state/tg.json` — офсет бота, очередь звуков, задания и их статусы, идеи владельца. Коммитить!
- `jobs/<id>/` — в git только `spec.py`, `meta.json`, `transcript.txt`; медиа игнорируются.
- `legacy/` — старые скрипты из архива, только для справки.

## Формат spec.py

Как в `examples/v30/spec.py` (LINES — слова с таймкодами, SC — интервалы карточек, GLOW, PEMO, END,
HTML — карточки `#c1..#cN`, RENDER — JS-анимация по `t`) плюс обязательные поля:

```python
DUR=15.0      # длина ролика, с
FADE=14.6     # начало затухания звука
START=0       # с какой секунды звука начинать
SONG='Артист — Трек'   # из shazam.py; пусто — плашки трека не будет
# LK=[(0,'idle'),(1.2,'wave',{'e':'👋'})]  # опционально: Лали поверх сцены (старый стиль)
```

**ВСЕ таймкоды (LINES, SC, END, RENDER) — абсолютные секунды исходного звука**, как в transcript.txt:
ролик идёт от START до START+DUR. Если START=43.9, первое слово ≈44.3, а END≈[START+DUR-0.4, START+DUR].
Не считай от нуля! `build.py` проверяет это и падает, а `make.sh` бракует ролик с чёрным экраном — такое видео не отправлять.

Ролик 10–25 с: выбери самый цепляющий кусок (припев/панчлайн), START = его начало.
Одна карточка на строчку, визуальная шутка буквально по смыслу строки (чат, уведомление, график,
банковское приложение, профиль, карта…), Лали реагирует. Мат в субтитрах маскируй звёздочкой (`с*ка`).
Перед рендером проверь превью 3–4 кадров (`render.js … times`) — текст не вылезает, карточки читаются.
